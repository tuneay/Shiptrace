# Support

Shiptrace is a community-maintained open source project without a hosted support service or guaranteed response time.

Before asking for help:

1. Read `README.md` and `DOCS_INDEX.md`.
2. Confirm you are using Node.js 20.9 or newer.
3. Run `npm run typecheck`, `npm run lint`, and `npm test`.
4. Check whether the problem still occurs without optional GitHub or Groq credentials.
5. Remove all secrets and personal data from logs or screenshots.

For reproducible bugs, use the bug-report issue form. For scoped product proposals, use the feature-request form. Security vulnerabilities must follow `SECURITY.md` and must not be posted publicly.
